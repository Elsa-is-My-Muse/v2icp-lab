## B. 规范与公开资料

规范官方入口：`https://knowhow.vdv.de/documents/261/`。

当前协议模型**缺少独立的条款级复核**，信号字典记录的是源码行为而非标准认证结论。项目不绕过规范访问权限，也不重新分发 VDV261_en.pdf 或其他受版权保护的标准。在产品使用前应补齐：

1. 标准完整名称、版次、日期和合法来源。
2. 每个信号的表号/条号、单位、偏移、分辨率、枚举、SNA、方向和必选条件。
3. HTTP/TLS、认证、错误响应、重试/恢复、长时连接和断链边界。
4. InternetAccess VAS 与目标 ISO 15118 版本的对应关系、免费服务选择、地址/路由和会话生命周期。
5. 标准一致性用例与独立互操作结果。

Python 官方 `http.server` 文档明确其不建议用于生产；本项目因此仅绑定本机回环，不宣称网络边界足以保护公网部署。参考入口：`https://docs.python.org/3/library/http.server.html`。

W5500硬件能力应查询 WIZnet 官方产品资料/数据手册，而不是假设启用IPv6转发开关就完成网关。参考入口：`https://docs.wiznet.io/`；具体器件版本、工作模式和主机网络栈方案由硬件集成者确认。

## 已知缺口

- 无PLC/SLAC、VAS、EXI集成，无真实路由/RA/NDP，无真实CAN或车辆执行。
- 未实现所有连接恢复时序、网络断续、后台幂等持久化和长期稳定性机制。
- 部分HTTP响应接收超时、TLS重协商/吊销策略等不是完整生产实现。
- 没有完整硬件可制造资料，无EMC/绝缘/安规/高压验证记录。
- 本地证书有效期30天，不自动续期，不提供生产凭据托管。
- UI是单用户本机开发服务，CSRF/Host检查不等于抵御恶意本地用户或共享主机攻击。
- 脱敏只针对当前字段与已知身份/密码文本，不保证未来新增任意日志都自动安全。
