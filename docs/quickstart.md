# 快速上手与排错

## 1. 环境准备

项目根目录执行：

```powershell
python --version
openssl version
python -c "import socket; s=socket.socket(socket.AF_INET6); s.bind(('::1',0)); print(s.getsockname()); s.close()"
```

要求 Python 3.10+、OpenSSL 可执行文件以及 IPv6 回环。软件仅使用 Python 标准库；无须 `npm install` 或 `pip install`。可选浏览器测试才需要 Playwright。

Windows 的 `python` 若指向商店占位程序，可先安装 Python 或尝试 `py -3`；把下面命令中的 `python` 一并替换。请使用可信发行渠道安装系统依赖，本项目不自动下载安装程序。

## 2. 启动可视化

```powershell
python -m demo.web --open
```

访问 `http://127.0.0.1:8765/`。双击 `start-lab.cmd` 等效。不要双击 `app.js` 或单独打开 HTML；页面需要本地 API。若端口被占用：

```powershell
python -m demo.web --port 8876 --open
```

Web 服务只绑定本机 IPv4 回环，实验内部用 IPv6 `::1`。打开 UI 不需要后台管理员账号。

## 3. 第一次实验

1. 点“自动运行”，等待证书生成与连接。首次稍慢；失败信息会显示在界面。
2. 看见 TLS 版本、TX/RX 计数及两端随机端口，说明真实本机链路已工作。
3. 后台 target_soc 输入 `90`，点“应用后台计划”，观察下一轮 RX 的 `90`。
4. 车辆 odo 改为 `5100`，点“应用车辆数据”，下一帧包含变化字段，随后不变时省略。
5. 点“停止”保留结果；参数修改只存在当前 Web 进程内，不改写 `demo/config.json`。重新启动会话保留当前进程内参数；退出整个 Web 服务才恢复配置文件值。

界面“下一序号”是下一次新请求的序号，不是最近 RX 序号；重传保留原序号。TX 计数含重传，RX 只计通过校验的响应。

## 4. 一帧一帧学习

停止自动模式后点“单步收发”。第一次建立连接并发 seq=0 全量。再点一次发下一帧。未点击时不自动发送。单步按钮不保证快速连点排队多个请求；等当前帧完成再操作。

在单步会话中选“响应序号错误”并注入，然后单步：拒绝计数增加，有效 RX 保持旧值。再次单步可恢复。选“丢弃一次响应”再单步：等待超时后同帧重发。

超大响应会关闭连接，会话变异常，需重新启动；不是程序崩溃。最多三次无响应后停止，无长期生产重连策略。

## 5. 时间设置

| 预设 | 周期间隔 | 等待响应超时 | 用途 |
|---|---|---|---|
| 快速演示 | 1 秒 | 2 秒 | 交互学习，加速实验，非规范时序 |
| 参考时序 | 10 秒 | 15 秒 | 复现本项目参考周期；不代表全部规范行为 |
| 自定义 | 0.1–60 秒 | 0.1–30 秒 | 故障/性能实验 |

周期从本轮响应处理完成后开始等待，不保证严格墙钟频率。运行期间时序输入禁用，先停止再修改。

## 6. 保存结果

右上角导出 JSON 会移除密码/Authorization，并脱敏本项目记录的 VIN/EVCCID。仍应人工审查异常文本、备注或未来新增字段，尤其不要把生产日志直接发到公开 Issue。

命令行兼容原用法：

```powershell
python -m demo.run_demo --interval 1 --cycles 4
```

`--interval 1` 是完整参数；单独 `--interval` 缺少数值。CLI 的原始报告 `output/demo_report.json` 未脱敏，仅供本地检查。

## 常见问题

| 现象 | 排查 |
|---|---|
| `No module named demo` | 先进入含 README 和 demo 文件夹的项目根目录 |
| `openssl is required` | 确认 `openssl version` 成功，再重开终端继承 PATH |
| 证书验证失败 | 核对系统时间、证书有效期；停止程序后仅移走本项目 `.demo_certs` 目录让它重新生成，勿删除系统证书 |
| 不能绑定 `::1` | 检查系统 IPv6 回环；本项目不通过偷偷降级 IPv4 掩盖问题 |
| UI 提示 token/Origin 错误 | 用服务打印的本机地址重新加载；不要通过反向代理或其他域名访问 |
| 页面打不开 | 终端必须仍在运行；换 Web 端口，核对地址不是内部 TLS 随机端口 |
| RX 不出现目标值 | 点击“应用后台计划”；确认下一轮已发送；若错误序号被拒绝，旧值保留是预期 |
| 输出四轮 PASS 后回到终端 | CLI 默认四轮即结束；UI 自动模式会持续至停止 |

## 退出

先点“停止”，再在启动它的终端按 `Ctrl+C`。关闭浏览器标签页**不会停止** Python 服务和正在运行的实验。不要把开发服务对公网开放。
