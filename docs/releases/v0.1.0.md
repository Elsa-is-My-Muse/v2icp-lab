# V2ICP Lab 0.1.0

首个公开版本，面向 VDV 261 / V2ICP 学习与嵌入式接入讨论。

## 功能

- 本机IPv6 / TLS1.2 / HTTP通信，模拟EVCC、字节中继和调度后台。
- 浏览器自动/单步操作、动态信号、原始/解析值、统计和事件时间线。
- 丢响应、错误序号、错误VIN、503和超长响应实验，以及脱敏JSON导出。
- 全量/增量、SNA、身份/序号校验和有限次数同帧重传。
- 硬件参考架构、BOM、接口核对表、低压验证清单及C目标接纳边界。

## 开始使用

需要Python3.10+、OpenSSL及IPv6回环。在源码目录运行 `python -m demo.web --open`；Windows可双击 `start-lab.cmd`。

## 验证

Windows本地65项自动测试、CLI、真实Chrome交互、C99主机示例和干净副本复现均已通过。首轮GitHub CI中Windows/Linux × Python3.10/3.13四组测试与Linux C主机任务均通过。每个提交的最终状态以仓库Actions记录为准，详见 `docs/validation-record.md`。

## 使用限制

硬件资料是接入参考，不含可制造PCB或生产固件。PLC/SLAC、InternetAccess VAS、真实IPv6网关和CAN执行尚未集成，未做上板或整车测试。协议模型仍需目标规范版次的独立复核；本项目不是官方实现或认证工具。仅限本机教学，不用于实际充电控制或公网服务。
