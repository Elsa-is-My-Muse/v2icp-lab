# 本项目的信号字典

**本表记录当前源码行为，不替代 VDV 261 原文。** 原始编码范围及枚举语义必须由合法持有目标版本规范的人复核；不能仅凭演示成功宣布互操作。

| 方向 | 字段 | 当前 raw 范围 | SNA | 当前用途 |
|---|---|---|---|---|
| 双向 | seq | 0..255整数 | 无 | 请求与响应匹配，回绕 |
| 双向 | vin | 17 ASCII字母数字 | 无 | 合成车辆身份；响应须与请求相同 |
| 车→后台 | evccid | 12十六进制字符 | 无 | EVCC测试身份 |
| 车→后台 | odo | 0..21055406 | -1 | 里程信号原始编码 |
| 车→后台 | bat_reqtime | 0..250 | -1 | 电池需求时间编码 |
| 车→后台 | bat_eamount | 0..1000 | -1 | 电池需求能量编码，不解释为“必定充满到100%” |
| 车→后台 | prec_eamount | 0..1000 | -1 | 预调节能量编码 |
| 车→后台 | prec_reqtime | 0..250 | -1 | 预调节时间编码 |
| 车→后台 | chrg_stat | 0..4 | -1 | 充电状态枚举；GUI不猜测全部枚举语义 |
| 车→后台 | h2_stat | 0..1 | -1 | 氢系统状态，每帧包含；默认未知 |
| 车→后台 | bat_stat | 0..1 | -1 | 电池状态，每帧包含；示例值不可等同真实安全结论 |
| 后台→车 | driveoff | 0..288 | -1 | raw×5分钟；界面以业务分钟输入 |
| 后台→车 | prec_dsrd | 0..1 | -1 | 预调节请求枚举 |
| 后台→车 | prec_hvac | 0..3 | -1 | 空调模式原始枚举，含义对照目标规范 |
| 后台→车 | ambienttemp | -50..70 | -51 | 本模型按°C显示；-1是有效温度 |
| 后台→车 | target_dist | 0..1000 | -1 | 目标里程原始编码 |
| 后台→车 | target_soc | 0..100 | -1 | 本模型按目标百分比显示 |

目前 `Signal.resolution` 除 driveoff 为5以外均为1。这仅代表本程序的 raw→display 处理；其他能量、时间、里程信号的物理单位/偏移尚未依据规范逐项确认，界面因此保留 raw 字样，不把它们武断标成kWh、km或分钟。

所有信号要求真正整数，拒绝 Python/JSON boolean 冒充整数。未知字段在协议校验中忽略（便于前向兼容），而本地UI参数变更接口拒绝未知信号，防止把后台字段写错方向。

## 快照与时序

- 请求首次、seq=0、或新连接时全量；其后变化字段+seq/vin/evccid/h2_stat/bat_stat。
- 后台合并车端增量；响应当前实现发送全部后台信号。
- 客户端先校验HTTP状态、JSON、范围、seq/VIN，再合并有效后台值；失败不覆盖已接收有效值。
- 发车倒计时采用monotonic时钟，除以300秒向上取整并不小于零；未知输入None产生SNA，不代表立刻发车。
- 执行层不是此表的一部分：任何真实BMS、HVAC或VCU写入都必须经过整车权限、状态、时效和安全检查。
