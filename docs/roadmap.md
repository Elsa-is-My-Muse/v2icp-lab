# 路线图

## 当前版本：0.1.0

目标是把应用层通信讲清楚，并提供可复现的本机实验。支持真实IPv6/TLS/HTTP、可视化单步、动态参数和异常注入；提供硬件接入参考与主机C边界示例。

## 下一阶段

按依赖关系推进，不为未完成工作承诺发布日期：

1. **规范映射**：确认目标版次，为信号、时序和异常处理建立条款映射及回归用例。保留引用位置，不分发标准全文。
2. **网络鲁棒性**：完善部分HTTP响应超时、断链、重连、幂等与计划过期策略，加入更长时间的压力测试。
3. **独立互操作**：与独立实现的测试后台核对认证、字段、单位与错误行为，而不只用本仓库两端互测。
4. **低压硬件接入**：验证PLC、VAS、IPv6路径和充电/数据双连接，记录资源消耗与故障隔离结果。
5. **授权车辆接口**：先读状态和mock，再接整车策略队列；执行器测试由符合项目安全要求的台架负责。
