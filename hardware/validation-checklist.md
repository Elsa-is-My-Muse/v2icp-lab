# 低压接入与分阶段验证清单

所有条目初始均为待验证。软件测试通过不能代替这里的硬件证据。发现安全问题应退出实验，不尝试靠后台数据或软件屏蔽保护来继续。

## H0 · 文档和权利

- [ ] 记录板卡型号、硬件版本、MCU和实际PLC/网络模块。
- [ ] 获得合法板图、引脚表、模块资料和（如需要）授权DBC，不直接公开私人资料。
- [ ] 确定低压供电要求、限流、隔离、ESD、调试接地与故障退出流程。
- [ ] 明确没有连接高压/执行器，或者由合格人员提供受控台架与独立安全批准。
- [ ] 对目标规范版次完成逐条信号/时序复核，记录差异。

## H1 · PC基线

- [ ] 自动测试通过；界面能自动/单步收发。
- [ ] 更改SOC并观察；错误序号拒绝；丢包同帧重发；报告人工审查无敏感数据。
- [ ] 保存环境版本、测试输出和已知限制。

## H2 · 网络台架，不接整车执行器

- [ ] 验证端到端IPv6可达，而非只证明SECC能IPv4访问后台。
- [ ] 记录地址、前缀、路由、MTU、NDP/RA来源和防火墙规则。
- [ ] 验证EVCC所校验的证书身份为后台，而非无意中的TLS代理。
- [ ] 断开后台上联只影响数据服务；确认充电状态机遵循既定安全策略，不被阻塞或误复位。
- [ ] 记录所有私有网络地址，不将未脱敏抓包上传公开仓库。

## H3 · 固件双连接

- [ ] A/B连接有独立socket/TLS、EXI/HTTP缓冲、序号和超时状态。
- [ ] V2ICP任务不占用原充电收发缓冲，不在高优先级任务中阻塞等待后台。
- [ ] 实测RAM峰值、任务栈水位、CPU和TLS握手耗时，预先给出项目可接受阈值。
- [ ] 测试关闭B不会关闭A；后台拒绝/慢响应/超长包不会污染A。
- [ ] 车端新连接全量；序号回绕；未知数据SNA；生产恢复要求有独立测试。

## H4 · 经授权的整车接口

- [ ] 从只读CAN状态或mock开始；不以演示输入冒充真实BMS状态。
- [ ] 有效身份、序号、范围、时效和权限检查之后才进入目标队列。
- [ ] VCU/BMS/HVAC本地安全逻辑有最终裁决权；未知/失联/过期方案明确。
- [ ] 需求被接收、被批准、被执行、达到目标分别记录，不混写“成功”。
- [ ] 台架异常和看门狗退出符合项目安全要求，经过批准再进入后续阶段。

## H5 · 发布证据

- [ ] 测试记录包含硬件/固件/后台版本、日期、操作、期望、实际和原始日志索引。
- [ ] 待测项保持“未测试”，失败保留证据，不删掉失败记录伪装全通过。
- [ ] 去除标准全文、私有图纸/固件、凭据、真实VIN和用户数据。
- [ ] 由拥有者审查授权后再提交，说明适用范围、已知缺口和许可证。
